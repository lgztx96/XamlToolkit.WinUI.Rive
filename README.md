# XamlToolkit.WinUI.Rive

`XamlToolkit.WinUI.Rive` is a **WinUI 3 Rive control implementation** built on top of the  
**C++ ports of the WinUI Community Toolkit**.

This repository is a **sub-project** of the Community Toolkit C++ ecosystem and is maintained **separately** from the XamlToolkit.WinUI repository. It is provided as a **standalone extension module** that follows the same architectural conventions, coding style, and development practices used across the Community Toolkit C++ ports.

`XamlToolkit.WinUI.Rive` is intended to be consumed explicitly by projects that require Rive animation support in WinUI 3, rather than as a default toolkit dependency.
